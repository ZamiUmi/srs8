# Post Explorer

## Описание проекта

**Post Explorer** — Flutter-приложение для просмотра и создания публикаций с использованием API JSONPlaceholder.

Приложение позволяет просматривать публикации, искать их по заголовку, фильтровать по автору, сортировать по ID, открывать подробности и просматривать комментарии. Также пользователь может создавать публикации через форму.

## Используемые технологии

- **Flutter и Dart** — разработка приложения.
- **Dio** — HTTP-запросы.
- **Retrofit** — описание API-запросов.
- **json_serializable** — преобразование JSON в модели Dart и обратно.
- **Hive** — локальное кэширование публикаций.
- **Mocktail** — создание mock-объектов в тестах.
- **flutter_test** — запуск автоматических тестов.

## Основные возможности

- Загрузка публикаций с JSONPlaceholder.
- Пагинация — загрузка публикаций по 10 элементов.
- Поиск по заголовкам загруженных публикаций.
- Фильтрация по автору.
- Сортировка по ID.
- Просмотр публикации и её комментариев.
- Создание публикации с проверкой введённых данных.
- Локальное отображение созданных публикаций.
- Кэширование публикаций и обработка ошибок загрузки.

## API

Используется API: https://jsonplaceholder.typicode.com

Основные запросы:

- `GET /posts` — получение публикаций.
- `GET /posts/{id}` — получение одной публикации.
- `GET /posts?userId={id}` — фильтрация по автору.
- `GET /posts/{id}/comments` — получение комментариев.
- `POST /posts` — отправка новой публикации.
- `GET /users` — получение пользователей.
- `GET /users/{id}` — получение пользователя по ID.

**Примечание:** JSONPlaceholder имитирует создание публикаций. Отправленные данные не сохраняются на сервере постоянно, поэтому приложение дополнительно отображает созданную публикацию локально.

## Запуск проекта

1. Установить Flutter SDK.
2. Скачать или клонировать репозиторий.
3. Открыть папку проекта в терминале.
4. Выполнить команды:

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

## Тестирование

Для запуска автоматических тестов выполните:

```bash
flutter test
```

Для проверки кода выполните:

```bash
flutter analyze
```
